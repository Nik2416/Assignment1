# Assignment 1 - Basic Python Programs

This repository contains solutions to 10 basic Python programming problems. These programs were created to practice Python fundamentals such as variables, loops, conditional statements, strings, lists, and user input.

## Topics Covered

- Taking input from the user
- Conditional statements (`if`, `elif`, `else`)
- Loops (`for`, `while`)
- Lists and list operations
- String manipulation
- Counting vowels and consonants
- Removing duplicate characters
- Number-based programs
- Basic problem-solving using Python
